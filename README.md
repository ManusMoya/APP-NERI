# APP-NERI
Sistema web simple para gestionar compras, ventas, productos, fábricas, clientes y balance. Desarrollado con React + Vite, preparado para futura integración con Supabase y despliegue en Cloudflare Pages. Pensado para uso fácil desde navegador, incluyendo celular, con una interfaz clara para registrar operaciones y consultar saldos.
